## SkyFi - Flight Booking App

A flight booking mobile app UI built using FlutterFlow's drag-and-drop builder, designed during first year as an early exploration into app design and no-code development.

### Overview

SkyFi is a concept flight booking application featuring a clean, modern interface for searching and booking flights. Built entirely through FlutterFlow's visual development environment.

### Built With

- FlutterFlow (Visual app builder)
- Flutter/Dart (auto-generated)
